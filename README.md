# Heaven & Home — Luxury Furniture E-Commerce

A complete furniture e-commerce website built with React + Vite + Tailwind CSS.

**Live demo:** https://noreen11x.github.io/heaven-and-home/

## 🚀 Quick Start

Requires Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
```

---

## 📁 Project Structure
```
heaven-and-home/
├── src/
│   ├── App.jsx        ← All pages & components
│   └── index.css      ← Global styles + Tailwind
├── index.html
├── package.json
├── tailwind.config.js
└── vite.config.js
```

## 📄 Pages Included
| Page | How to access |
|------|--------------|
| Homepage | Default landing page |
| Product Catalog | "Shop" in nav |
| Product Detail | Click any product card |
| Shopping Cart | Cart icon (top right) |
| Checkout | From cart page |
| Register | "Login" → "Sign up" |
| Login | "Login" in nav |
| User Dashboard | After login |
| Admin Dashboard | "Admin" badge (after login) |
